
# Scorpio Cafe – Website Redesign Concept

## Project Overview
This project is an independent student-created website redesign concept for Scorpio Cafe, located in Mayur Vihar Phase 2, East Delhi.

The objective is to create a professional and responsive online presence that makes business information, food categories and location details easier for visitors to explore.

## Technologies Used
- HTML5
- CSS3
- JavaScript
- Google Maps Embed
- GitHub Pages

## Website Features
- Responsive navigation bar
- Attractive landing page
- About section
- Food category cards
- Popular food highlights
- Image gallery
- Contact information
- Google Maps location
- Demonstration enquiry form
- Scroll animations

## Business Location
Scorpio Cafe  
G-4, Durga Complex, Pocket B,  
Mayur Vihar Phase 2, New Delhi.

## Project Status
Completed as an independent student redesign concept.

This website is not the official website of Scorpio Cafe. Business information and illustrative photographs should be verified before commercial use.
